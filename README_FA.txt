JARVIS برای Windows 10 — نسخه اولیه دسکتاپ

قابلیت‌های این نسخه:
- پنجره چت فارسی با ورودی متنی
- دریافت فرمان صوتی فارسی از میکروفون (نیازمند اینترنت برای تبدیل گفتار)
- پاسخ صوتی با موتور صدای نصب‌شده ویندوز (وجود صدای فارسی به تنظیمات Windows بستگی دارد)
- اجرای چند فرمان مجاز: بازکردن YouTube، Google، مرورگر، ماشین‌حساب، Notepad و File Explorer
- چت هوشمند اختیاری با OpenAI API

نصب:
1) Python 3.11 نسخه 64-bit را از https://www.python.org/downloads/release/python-3119/ نصب کن.
2) هنگام نصب، گزینه Add Python to PATH را فعال کن.
3) اینترنت را وصل کن و روی install.bat دوبار کلیک کن.
4) بعد از نصب، روی run.bat دوبار کلیک کن.

فعال‌سازی هوش مصنوعی:
- برای چت هوشمند، یک API key از داشبورد API خودت بگیر.
- کلید را در کادر بالای برنامه وارد کن. کلید در برنامه ذخیره نمی‌شود.
- استفاده از API ممکن است هزینه جداگانه داشته باشد و به حساب API نیاز دارد؛ اشتراک ChatGPT به‌تنهایی لزوماً اعتبار API نیست.
- این برنامه درخواست‌ها را به OpenAI Responses API می‌فرستد؛ متن ارسالی برای پردازش به سرویس منتقل می‌شود.
- اگر کلید وارد نکنی، فرمان‌های محلیِ آماده همچنان کار می‌کنند.

محدودیت‌ها و امنیت:
- این یک نسخه اولیه قابل اجراست، نه فایل نصب‌کننده EXE امضاشده.
- اجرای آزاد هر فرمان سیستم، حذف فایل، ارسال پیام، خرید، خاموش‌کردن یا کنترل نامحدود موس و صفحه‌کلید عمداً فعال نیست.
- تشخیص صدا برای تبدیل گفتار به متن به اینترنت نیاز دارد.
- اگر نصب PyAudio خطا داد، Python 3.11 64-bit را بررسی کن و دوباره install.bat را اجرا کن.
- کلید API را با دیگران به اشتراک نگذار.
- قبل از استفاده، میکروفون و مجوز دسترسی آن در Windows Settings را بررسی کن.

عیب‌یابی:
- اگر py شناخته نشد: Python را دوباره نصب کن و Add Python to PATH را تیک بزن.
- اگر میکروفون کار نکرد: Settings > Privacy > Microphone را بررسی کن.
- اگر صدای فارسی ندارد: یک صدای فارسی در Windows نصب کن؛ در غیر این صورت پاسخ‌ها در پنجره نمایش داده می‌شوند.
